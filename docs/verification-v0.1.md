## 问答输入区与附件补充验证

使用独立 SQLite 数据目录、真实 Pi SDK 和本地模型接口测试桩验证，未修改用户项目的模型配置：

- 浏览器按钮一次选择图片和 Markdown 文件，预览与移除按钮正常；Enter 后创建一条运行并清空草稿，Shift+Enter 保留换行。
- 粘贴 PNG 图片显示 `clipboard.png` 缩略图；仅发送图片也成功。接口测试桩确实收到图片 data URL 和文档内特定标记 `attachment_ui_520`。
- 在浏览器中派发组合输入和 `isComposing` 回车事件，没有新增运行；内嵌浏览器不支持原生 IME 仿真，未代替真实输入法逐一验收。
- 上传不支持的二进制文件时显示错误，已输入文本和图片仍保留；移除错误文件后可继续发送。
- 桌面及 390px 窄屏测量，文本框与发送按钮不重叠，页面没有横向溢出。附件较多时预览区可滚动。
- 自动测试验证 PDF/DOCX 实际正文提取、文本截断、空文件/损坏图片/超限拒绝、跨项目附件读取和引用拒绝、SQLite 重启后原文件与正文保持一致。
- Pi SDK 测试验证图片随会话续接保留，自定义文本模型拒绝图片；界面拖放入口已接入，受浏览器自动化能力限制未执行真实桌面文件拖放验收。

- 20 个 Go 测试通过 race 检查；`go vet ./...`、前端语法检查与嵌入资源构建通过。
- 真实 Git HTTP 测试服务要求用户名/Token：分支发现、clone、fetch 与文件读取通过；错误 Token 和不带凭据请求被拒绝，Git 配置不落秘密。
