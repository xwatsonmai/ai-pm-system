## 第二轮代码审查

三条并行审查线覆盖权限与数据暴露、版本并发与迁移、前端异步请求与草稿。确认的问题均已修复并补充回归：

- 所有人工发起的分析继承发起人权限，每次工具调用及沙盒继续执行时重新检查。个人 Web 与 OAuth MCP 以同一员工身份判断归属；私有运行、历史输出和保存的分析证据使用同一权限规则，列表总数在分页前过滤。

- 关闭默认版本及选择继任版本在事务内校验默认指针和继任版本的读取依赖，防止同时关闭后留下无效默认值。旧版本的关联 Bug 继续处理时，父子记录原子迁入活动版本，已发布快照保留。

- 数据格式或权限语义不兼容旧版本时，更新脚本支持显式 `--no-image-rollback`：启动失败停止目标并保留现场和备份，禁止自动启动旧写入程序。正常兼容升级的默认恢复行为保留。
