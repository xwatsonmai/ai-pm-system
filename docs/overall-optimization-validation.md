## 边界

- 无分页参数的旧列表接口保留原返回形状，新工作台使用分页接口；已验证服务端兼容契约，未发布或实测新的原生桌面客户端。
- 评审聊天室仍使用单个 JSON 文档保存。业务状态计算读取完整文档，Web 响应按消息游标裁剪；本次未迁移为独立消息表。
- 权限只到页面层，页面内保留现有业务操作与流程校验，不提供独立按钮/字段或只读模式配置。
- 此处记录通用源码的隔离测试，不代表真实员工登录、模型调用或人工业务验收。测试中的上线登记使用临时数据；部署记录由各部署环境另行维护。

## 第二轮代码审查

三条并行审查线覆盖权限与数据暴露、版本并发与迁移、前端异步请求与草稿。确认的问题均已修复并补充回归：

- 所有人工发起的分析继承发起人权限，每次工具调用及沙盒继续执行时重新检查。个人 Web 与 OAuth MCP 以同一员工身份判断归属；私有运行、历史输出和保存的分析证据使用同一权限规则，列表总数在分页前过滤。
- 附件下载与复用检查实际业务关联和会话归属。上传者只能预览尚未绑定的草稿，不能凭 ID 或 URL 越权读取已绑定附件。旧有真实绑定保留；没有可核验上传者和业务关联的孤立旧草稿需要重新上传。
- 关闭默认版本及选择继任版本在事务内校验默认指针和继任版本的读取依赖，防止同时关闭后留下无效默认值。旧版本的关联 Bug 继续处理时，父子记录原子迁入活动版本，已发布快照保留。
- 任务详情、代码、版本、成员与角色异步请求绑定原容器和最新请求；过期响应不能覆盖后续页面或弹窗。模型翻页保留尚未保存的默认选择。
- 数据格式或权限语义不兼容旧版本时，更新脚本支持显式 `--no-image-rollback`：启动失败停止目标并保留现场和备份，禁止自动启动旧写入程序。正常兼容升级的默认恢复行为保留。
